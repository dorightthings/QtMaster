# 当前模型

本分支只暴露一个 `build_model()` 入口，模型为市场条件因子重标定、市场条件化LLA、
PureMLP和标量读出头。构造和训练不依赖历史实验产物。

## 输入与模块

输入为 `[B,8,221]`，前158列是股票因子，后63列是市场信息；标签列不得进入模型。
输出为 `[B,1,1]`。

| 部分 | 定义 | 可训练参数 |
| --- | --- | ---: |
| 因子重标定 | `2*sigmoid(M @ W)`，W为63×158 | 9,954 |
| LLA核心 | 因子位移、逐日共享表示、融合与残差 | 61,760 |
| 市场条件头 | `Linear(63,32) → GELU → Linear(32,158)` | 7,262 |
| PureMLP | 历史维度8→256→256→256→1 | 134,145 |
| 读出头 | `Linear(158,1,bias=False)` | 158 |
| 合计 | 所有部分联合训练 | 213,279 |

每天的市场信息用于当天历史位置的因子重标定。时间偏移则使用窗口最后一个已观测交易日的市场向量：

```text
tau = 3 * tanh(raw_tau + 0.1 * tau_head(last_observed_market63))
```

`tau` 为158个因子的相对历史位置偏移，随输入市场状态变化。
0.1是tanh之前的修正缩放系数，不是“最多偏移0.3天”的限制。
没有单独的最佳生效时间标签，这些偏移不表示已识别的因果时滞。

LLA将8日序列补零至16后进行FFT位移，在对齐位置生成逐日共享表示并融合，再用负位移回移，
最后进行有界残差融合。补零和裁剪使两次位移不保证严格互为逆算子。

## 初始化和训练

因子重标定的W零初始化，开始时为恒等门控；条件头末层零初始化。
条件头与LLA核心的初始化不推进外层训练随机数状态。
PureMLP仍按完整上游构造顺序初始化，再移除禁用的时间查询和截面注意力部件，
以保留当前模型的初始权重与随机数消耗顺序。

所有可训练参数交给一个Adam参数组，不冻结骨干、不为条件头设置单独学习率。
`cycle=7`或3为接口兼容字段，当前PureMLP前向不使用其值。
